## 后续更新约定 / Versioning policy

每次修改同步 VERSION、首页版本与本文件，记录日期及具体变更；保留 Git 历史，不覆盖旧命名安装包。小修复加补丁号，新增兼容流程加次版本，不兼容变化加主版本。  
For every update, change VERSION, homepage and changelog together. Record the date and changes, preserve Git history and keep old named bundles. Use patch versions for fixes, minor versions for compatible additions and major versions for breaking changes.
